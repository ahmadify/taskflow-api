# Project Rules

These rules apply permanently to all work in this repository.

- Use natural professional wording.
- Do not use emojis.
- Do not mention AI.
- Avoid decorative badges and excessive headings.
- Use consistent JSON response structures.
- Use Laravel Sanctum for token authentication.
- Use Form Request classes for validation.
- Keep controllers concise.
- Write feature tests for authentication and CRUD functionality.
- Do not install software or scaffold Laravel during this phase.
